# Arthexis 1.0.0 Baseline

Arthexis 1.0.0 begins a new canonical source history.

The root commit is a source snapshot of the verified pre-cutover tree
`2bfb4207ea5f172c4e9aecc2b4442a7fab0dcb79`, selected from legacy commit
`8ac99f4f14a56aa14243ebfed5b0dc9328f3a312`.

The former repository is retained privately and read-only as
`arthexis/arthexis-legacy` for release, upgrade, and audit evidence. It is not
the canonical source repository for new work.

This baseline intentionally excludes retired application source, including
the Gallery, FTP, and web simulator apps. OCPP diagnostics requests remain in
the suite and use the Media Bucket upload destination by default. The supported
field OCPP simulator is owned by `gway-field-usb`, outside this repository.

Before publishing 1.0.0, validate the complete release pipeline and a bounded
upgrade replay from the legacy v0.11.0 release. No v1.0.0 tag is created by
this baseline commit.
